# موقع كريمة سليمان محمد هدهود

موقع تذكاري خاص، أُنشئ للحفاظ على ذكرى كريمة سليمان محمد هدهود، رحمها الله، وليبقى مكانًا يزوره أهلها ومحبوها كلما اشتاقوا إليها.

## محتوى الموقع

- **حكايتها** — قصة حياتها منذ طفولتها حتى رحيلها.
- **حياتها بالصور** — ألبوم صور عائلي من مراحل حياتها المختلفة.
- **أثرها فينا** — أبناؤها وأحفادها.
- **أشياء تركتها فينا** — ذكريات وعبارات ومواقف تخصها.
- **الدعاء** — آيات وأدعية للترحّم عليها.
- **رسالة شخصية** من حفيدتها حبيبة.

## اللغتان

الموقع متاح بالعربية (`index.html`) والإنجليزية (`index-en.html`)، مع رابط للتنقل بين النسختين.
